# ETRIVIUM IAM — Tema 3

**El Reglamento Orgánico del Gobierno y de la Administración del Ayuntamiento de Madrid, de 31 de mayo de 2004 (I): Las Áreas de Gobierno y su estructura interna. Órganos superiores; Órganos Centrales directivos. Número y denominación de las actuales Áreas de Gobierno.**

Material de estudio para la oposición **C1 — Técnico Auxiliar TIC del Ayuntamiento de Madrid** (temario BOAM 10.032).

## Contenido

- **`index.html`** — web autosuficiente (offline) con 7 pestañas: Inicio, Contenido, Diagramas, Test, Casos, Validación y Fuentes. Motor de test con corrección automática y penalización 1/3.
- **`tema-3-indice.md`** — índice y datos clave.
- **`tema-3-contenido.md`** — contenido teórico (13 secciones).
- **`tema-3-diagramas.md`** — 12 diagramas SVG.
- **`tema-3-test.md`** — 150 preguntas tipo examen + 20 pedagógicas.
- **`tema-3-caso-practico.md`** — 6 casos prácticos.
- **`tema-3-fuentes.md`** — registro normativo.
- **`tema-3-validacion.md`** — checklist de validación (María / Ana).
- **`tema-3-changelog.md`** — historial de versiones.

## Estado

**v1.0 — Pendiente de validación** por el IAM (María / Ana).

> Nota: el apartado "número y denominación de las actuales Áreas de Gobierno" es **actualizable** (lo fija el alcalde por decreto en cada mandato). Verificar el organigrama vigente en *transparencia.madrid.es* antes de cada convocatoria.

## Cómo regenerar el `index.html`

El `index.html` se **genera** a partir de los `.md` con `build_t3.py` (mantiene sincronizados HTML y fuentes). Editar los `.md` y volver a ejecutar el generador.
